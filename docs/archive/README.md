# Design archive

Designs kept for future use. None of this is in the game. Open any `preview.html` in a browser to see the design animated (no build needed); `entry.js` and `head.html` beside it are the sources.

| Folder | What | Status |
|---|---|---|
| `star-costumes/` | Three all-stars costume designs | A (Crown of Stars) is in the game; B (Celestial Mantle) and C (Moon Queen's Diadem) are kept for later |
| `paint-pumpkin/` | First paint looks: Splatter, Paint pour, Brushstrokes | Brushstrokes kept as a future skin for the White pumpkin |
| `paint-pumpkin/sketch/` | The owner's Paint pumpkin: pastel, big paint patches, normal stem; plus its **Masterpiece** skin (oil-painted body, painted face, black-tipped brush stem, ribbon trail) | Chosen design for a future pumpkin and skin |
| `nightmare-worlds/` | The Hallow's End map (world 6) and a nightmare version of each of the five worlds | In the game since 2026-09-28 as the nightmare storybooks and the Hallow's End sneak peek (`src/engine/render/nightmare/`); the playable nightmare levels are still to come |
| `hollow-king/` | The Hollow King, boss of Hallow's End: three animated forms (first, full, fallen), his five-stage fight and the Fallen Hollow King's nightmare fight | Kept for the Hallow's End release |
| `fallen-bosses/` | Nightmare "fallen" versions of the five story bosses, each animated beside the original | Kept for nightmare mode |
| `gourds/` | Five cute gourds for the nightmare worlds, each with its own shape, colour and (undecided) power; a gourd powers up pumpkins flicked from the 3×3 around it. Shown on a real frame of night 1-4 | Kept for nightmare mode (owner, 2026-11-02) |
| `nightmare-monsters/` | New nightmare monsters: mounted knights, vampire, witch and plague doctor variants, the Triptych Mirror Sprite, the Kraken, a pirate, the Blood Splitter Slime, the Hayrick, Casket Jack, two imp riders, burning variants and more Patch monsters | Kept for nightmare mode (2026-11-02) |
