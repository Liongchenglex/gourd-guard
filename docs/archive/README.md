# Design archive

Designs kept for future use. None of this is in the game. Open any `preview.html` in a browser to see the design animated (no build needed); `entry.js` and `head.html` beside it are the sources.

| Folder | What | Status |
|---|---|---|
| `star-costumes/` | Three all-stars costume designs | A (Crown of Stars) is in the game; B (Celestial Mantle) and C (Moon Queen's Diadem) are kept for later |
| `paint-pumpkin/` | First paint looks: Splatter, Paint pour, Brushstrokes | Brushstrokes kept as a future skin for the White pumpkin |
| `paint-pumpkin/sketch/` | The owner's Paint pumpkin: pastel, big paint patches, normal stem; plus its **Masterpiece** skin (oil-painted body, painted face, black-tipped brush stem, ribbon trail) | Chosen design for a future pumpkin and skin |
| `nightmare-worlds/` | The Hallow's End map (world 6) and a nightmare version of each of the five worlds | Kept for a later release |
