# The Fallen bosses (archive, 2026-10-21)

Nightmare versions of the five bosses of worlds 1 to 5, one per nightmare book, for the owner's nightmare mode (`dump.md`, `docs/WORLDS.md` §10). Open `preview.html` to see all five animated beside the boss as it is in the game, with every clip as strips and a game-size row; each boss folder also has its own `preview.html`, an `idle.png` still, and `fallen_<boss>.js`. Nothing here is in the game.

Each file is a copy of the boss's drawing function from `src/engine/render/chars/` (the first form and `form2` draw exactly as in the game; the Gravekeeper copy was checked pixel-identical) with a `P.variant === 'fallen'` look added at full-form size, keeping every clip and pose parameter. Each exports `FALLEN`, a registry entry in the format of `src/engine/render/chars/index.js`.

**Caveats shared by all five:** glow and `shadowBlur` are used freely because every clip is baked by `render/anim.js`; nothing may be painted per frame. The widened boxes would grow the shared atlas of that boss type, so in the game each fallen boss should get its own registry key (the `FALLEN.key` values here reuse the original names and would collide). The owner's new nightmare mechanics (black fog, rearranging the board, reaper phase, blood nets and spears, the clone and healing auras, sirens and whirlpools) are engine work and are not drawn here beyond the Tides' `skill` tell. The Fallen Twin Tides also need `twin` carried in the atlas key (`fallen-blood` / `fallen-blue`), since the game draws both twins from one entry today.

Rebuild any preview with its folder's `build.sh` (imports use absolute paths from the owner's machine). Published preview: https://claude.ai/artifact/7CVb1YT1da59g7pLq9uTF6
