# Hallow's End 6-5 to 6-8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Levels 6-5 to 6-8 with a two-boss night and the Emergency Pumpkins tool, in `VITE_W6` builds only, then deploy to the playtest link with the 6-1 Puddle Diver change.

**Architecture:** Levels are data in `world6.js`. A second boss is a new level field `boss2` beside `boss` (so every existing "is this a boss level" check keeps working); spawning uses a `'boss:<kind>'` key so each boss resolves its own kind. Emergency Pumpkins is a `GEAR` consumable introduced by 6-8's `unlockGear`, with a tray button shown only in `VITE_W6` builds.

**Tech Stack:** Plain JS ES modules, Vite 5, Canvas 2D; Playwright checks (`tools/w6_check.py`), smoke test, balance bot.

**Spec:** `docs/superpowers/specs/2026-10-31-hallows-end-6-5-to-6-8-design.md`

## Global Constraints

- Branch `w6-hallows-end` only; never touch `r1-ground-rules` or the store version (owner). Store builds (`npm run build`) must pass `w6_check.py --expect off` and the smoke test.
