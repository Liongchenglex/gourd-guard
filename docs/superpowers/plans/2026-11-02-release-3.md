# Release 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Beige pumpkin (glue on kill), Hallow's End 6-17 to 6-19, and 6-20 with the Hollow King, all tagged Release 3.

**Architecture:** Levels stay data in `src/data/worlds/world6.js` (already tagged 3 by `releaseOf`). Beige is a new `PTYPES` entry inserted before Rainbow behind `__RELEASE__ >= 3`; glue lives in a new `src/engine/glue.js`. The Hollow King is a boss kind `hollowking` whose phase/clone/power logic lives in a new `src/engine/hollowking.js`; each world boss form is an ordinary boss of that kind (reusing its kit code) drawn with the Hollow King art in a stage colour. Every new data entry and call site is gated with `__RELEASE__ >= 3` written directly in the expression so Rollup drops it from Release 1/2 builds.

**Tech Stack:** Plain JS ES modules, Vite 5, Canvas 2D; Python Playwright checks (`tools/w6_check.py`), `tools/smoke_test.py`, `tools/balance_bot.py`.

**Spec:** `docs/superpowers/specs/2026-11-02-release-3-design.md`

## Global Constraints

- Everything new is Release 3: `__RELEASE__ >= 3` inline; a `VITE_RELEASE=2` build and the store build contain no Beige, no glue, no Hollow King name or fight, no 6-17+ (spec "Hard rule").
- Never build a store app from `dev`; store build stays `STORE_RELEASE = 1`.
- Levels are data; no level numbers in the engine (`CLAUDE.md`).
- Bake every sprite; never `S.part`/materials or `shadowBlur` per frame (`CLAUDE.md`).
- Rules change → `docs/GAME_DESIGN.md` in the same commit.
- Stage files by name; never commit `dump.md`, `monetization.md`, `questdump.md`, `assets/music/drafts/*`. Commit trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- No network requests; test hook only with `?test`; original IP; no new sound files (reuse the bank).
- Deploy to the playtest link only when the owner says "deploy".
- Beige: buy 50 seeds after 6-16 (night 116); upgrades 5,000 coins, 10,000 coins, 50 seeds, 75 seeds; power `POWER`; glue 0.3 damage per 1 s, half speed, durations [1,2,3,4,5] s, shapes one/one/row3/row3/plus, no stacking, no refresh.
- Hollow King: original 60 health, 5 phases of 12; forms in order gravekeeper, poltergeist, hexwitch, vampirecount, twintides at their level-10 (form 1) health; original immune to all damage while a form lives; a power every 12 s in rotation wipe → smash → summon; fence smash = half the fence max in his lane, never below 1; summon 4–6 revisit monsters; 50% chance of a second boss chest.

## Review Focus

1. **Release-2 build leaks**: a constant left ungated (lore line, BOSS_NAMES entry, CHARS registration, economy row) puts "Beige"/"Hollow King" in the `VITE_RELEASE=2` bundle — pinned by `check_r3_absent` (Task 1, extended in Tasks 3, 5, 7).
2. **Type index shift**: inserting Beige moves Rainbow from 13 to 14 in R3 builds; any hard-coded 13, saved loadout or per-index table (`save.wardrobe.skins[t]`) breaks — pinned by `check_beige_save` (Task 3).
3. **One hit skipping a phase / killing the king early**: a 999 hit while open must stop at the phase floor and start the next split — pinned in `check_hk_phases` (Task 6).
4. **Continue night mid-fight**: phase, original health and the living form must come back — pinned in `check_hk_continue` (Task 6); 6-19 mid-jukebox state — pinned in `check_two_jukebox` (Task 2).
5. **Memory on phones**: six Hollow King atlases at ~533 px frames would be hundreds of MB; at most the original plus two stage atlases may be baked at once — pinned in `check_hk_atlases` (Task 5).
